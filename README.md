# MehmonGo Guest Services

Mobile-first hotel concierge for guests to request tours, transport, restaurant reservations, and tickets without registration.

## Live demo

[Kamilovs Hotel — Room 205](https://mehmongo-guest-services.xurshidaoldcity.chatgpt.site/?hotel=kamilovs&room=205)

## Local development

```bash
npm install
npm run dev
```

## Checks

```bash
npm test -- --run
npm run lint
npm run build
```

## Room plaque

```bash
npm run plaque -- "https://mehmongo-guest-services.xurshidaoldcity.chatgpt.site"
```

The current prototype simulates request submission in the browser. Telegram delivery, staff operations, hotel accounts, and financial analytics are planned for the backend phase.
